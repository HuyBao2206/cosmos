# Into the Cosmos · by HUB

Trang khoa học về vũ trụ, mang tính khám phá và giảng dạy: https://huybao2206.github.io/cosmos/

| Đường dẫn | Nội dung |
|---|---|
| `/` | Trang chủ: "Tỉ lệ của bạn" (Powers of Ten), lời mở đầu, ba cửa vào |
| `/kham-pha/` | Khám phá vũ trụ: hệ Mặt Trời 3D đúng vị trí hôm nay, hồ sơ các hành tinh, các vị thần trên bầu trời |
| `/thau-hieu/` | Thấu hiểu vũ trụ — sắp mở cửa |
| `/khao-luan/` | Khảo luận vũ trụ — sắp mở cửa |

HTML/CSS/JS thuần, ES modules, không có bước build. Thư viện tải từ jsDelivr (pin version).

## Chạy cục bộ

```bash
python3 -m http.server 8000
```
Mở http://localhost:8000/ . Kiểm thử cơ học quỹ đạo: `node --test tests/*.test.mjs`.
